# Отчет по результатам анализа узких мест и рисков при миграции системы

## Люди
| Проблема                                   | Как влияет на миграцию                                                           | Рекомендации                                                      |
|--------------------------------------------|----------------------------------------------------------------------------------|-------------------------------------------------------------------|
| Мало сотрудников в IT                      | Отсутствие ресурсов для переноса данных, настройки инфраструктуры и тестирования | Расширить команду или привлечь внешних экспертов                  |
| Нет опыта миграций                         | Ошибки в планировании, выборе инструментов и стратегии миграции                  | Провести обучение, привлечь архитектора миграций                  |
| Нет опыта управления микросервисами        | Сложности с поддержкой целевой архитектуры после миграции                        | Организовать обучение по микросервисам и DevOps                   |
| Недостаточно компетенций DevOps            | Невозможно внедрить CI/CD, обеспечить стабильность сред                          | Ввести DevOps-практики, нанять DevOps инженера                    |
| Фокус на поддержке 1С и Excel              | IT-команда загружена текущими задачами, нет времени на миграцию                  | Разделить обязанности, выделить группу миграции                   |
| Нет культуры работы с безопасностью данных | Слабое внимание к защите PII/PHI, риски конфиденциальности                       | Ввести обучение, разработать политику безопасной работы с данными |

## Технологии

| Проблема                            | Как влияет на миграцию                                              | Рекомендации                                    |
|-------------------------------------|---------------------------------------------------------------------|-------------------------------------------------|
| Монолитная архитектура              | Сложно выделить сервисы, высокая связность                          | Определить домены, провести декомпозицию        |
| Нет Api-слоя                        | невозможность изолировать функциональные модули, замедляет миграцию | Создать API Gateway, внедрить API               |
| 1С в файловом режиме                | Отсутствие транзакционности, риск потери данных                     | Перевести в клиент-серверный режим              |
| Excel и файлы вместо БД             | Ошибки при миграции, отсутствие консистентности                     | Создать единое хранилище, перенести данные в БД |
| Нет мониторинга, логов, трассировки | Трудно обнаружить деградации и ошибки                               | Внедрить ELK/EFK, Prometheus, OpenTelemetry     |


## Процессы

| Проблема                      | Как влияет на миграцию                          | Рекомендации                                |
|-------------------------------|-------------------------------------------------|---------------------------------------------|
| Множество ручных процессов    | Падение качества, ошибки                        | Автоматизировать основные операции          |
| Отсутствие автоматизации      | Высокая вероятность ошибок при миграции         | Внедрить ETL-пайплайны, CI/CD               |
| Нет тестирования              | Риск некорректной миграции                      | Создать тестовые среды, проводить регрессию |
| Отсутствие контроля изменений | Неконтролируемые изменения данных               | Ввести процесс управления изменениями       |
| Длительный цикл изменений     | Невозможно поддерживать две системы параллельно | Перейти на короткие релизы                  |

## Интеграции

| Проблема                                         | Как влияет на миграцию                      | Рекомендации                                       |
|--------------------------------------------------|---------------------------------------------|----------------------------------------------------|
| Устаревшие механизмы (OLE, файлы)                | Большой риск поломки после миграции         | Перейти на API/шину/очереди                        |
| Нет стандартизированных интерфейсов и контрактов | Затруднена декомпозиция архитектуры         | Создать контракты API, использовать OpenAPI        |
| Ручные интеграции (Excel, файлы, email)          | Ошибки, задержки, непредсказуемое поведение | Автоматизация интеграций                           |
| Отсутствие API для внешних и внутренних сервисов | Невозможно выделять микросервисы            | Внедрить API Gateway                               |
| Нет мониторинга интеграций                       | Сбои трудно обнаружить                      | Ввести мониторинг событий, трассировку             |
| Нет защиты данных при интеграциях                | Утечки PII/PHI                              | Использовать шифрование, подпись, контроль доступа |

## Окружение

| Проблема                      | Как влияет на миграцию                  | Рекомендации                             |
|-------------------------------|-----------------------------------------|------------------------------------------|
| Один физический сервер        | Риск отказа, отсутствие тестовых сред   | Перейти в облако, создать dev/stage/prod |
| Сервер рядом с пользователями | Зависимость от электричества, интернета | Разместить в ЦОД или облаке              |
| Отсутствие бэкапов            | Потеря данных при переносе или сбоях    | Настроить регулярные бэкапы              |
| Нет сегментации сети          | Высокие риски безопасности              | Настроить сетевую сегментацию            |

## Данные

| Проблема                              | Как влияет на миграцию                                | Рекомендации                                        |
|---------------------------------------|-------------------------------------------------------|-----------------------------------------------------|
| PII и медкарты лежат в Excel и файлах | Невозможно корректно мигрировать, грязные данные      | Создать единое хранилище данных, провести очистку   |
| Нет шифрования                        | Высокий риск утечек при переносе PII/PHI              | Внедрить TLS и шифрование at-rest                   |
| Нет журналирования доступа            | Ошибки и несанкционированные действия не фиксируются  | Ввести аудит и логи                                 |
| Нет классификации данных              | Нельзя определить, что защищать                       | Внедрить Data Catalog и теги                        |
| Нет Data Lineage                      | Неясно происхождение данных, сложно исправлять ошибки | Построить карту потоков, ввести lineage-инструменты |
